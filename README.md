# CRumina

CRumina 是一個使用 C++ 重寫 Rumina 項目的項目
<br>
其重寫目的是因為 jailbreak iOS 中沒有 rustc (至少在 rootless 和 roothide 中並未找到) 導致無法編譯 Rumina

## PR
歡迎`PR`如果發現有問題, 具體請查看`.github/submit-pr.md`裡面有提交流程
<br>
或者也可以直接提交不走`.github/submit-pr.md`的流程

## build
構建腳本已經製作完成
```bash
git clone --recursive https://github.com/AD-iOS/CRumina
cd CRumina
./build
```
